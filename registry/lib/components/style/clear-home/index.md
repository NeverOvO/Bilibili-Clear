4.1.0.5 · Beta 5 · 2026-11-02

项目标志采用带天线、表情与轻量闪光元素的蓝色小电视。设置、页面功能、竖屏与模式切换共用小电视轮廓，以屏幕内的滑杆、网格、播放和箭头区分操作，保留文字标签。功能窗口采用等宽等高网格：4 项时两列，6 项及以上在宽窗口中三列，窄窗口收为两列或一列；各功能内部弹窗与操作继续沿用。

所有普通页面，包括 UP 极简模式，左下角均有独立的设置与页面功能按钮，设置窗口内不再重复提供页面功能入口。模式按钮组统一从底部 140px 起排列，位于两个入口上方；点击模式按钮可在 **原版精简** 和 **关注极简** 之间切换，原有功能及设置保持可用。竖屏与全屏播放沿用隐藏浮动入口的行为。

极简首页显示“UP极简模式”，顶部 GitHub 图标与 NeverOvO 名称打开项目仓库。默认显示“视频”标签；切换“帖子”后以多列瀑布流展示内容，只显示已确认关注的作者，并按发布时间和日期分组。帖子标签右侧的“只看抽奖”复用已加载动态，并补取缺失的抽奖信息；暂时被筛掉的帖子也会继续识别，关闭后恢复全部帖子。筛选结果中的原生抽奖动态直接展示，不再收入“疑似广告”折叠组。筛选中每次加载更早内容最多读取 4 页，接口提前到末尾时停止。

普通帖子卡片最高为两屏，超出时在底部显示截断提示和完整内容入口。图片保持自然比例并紧凑排列，只加载阅读区域附近、未被卡片裁切的缩略图，并限制同时加载的数量；点击后在当前页读取原图放大，支持同帖上一张、下一张和 Esc 关闭。文章仅依据明确的文章类型、专栏 ID 或原生“投稿了文章”标记识别，不根据标题推断。文章以标题与封面显示，使用淡紫色卡片和“文章”标识，不在列表中展开整篇正文；点击标题或原文入口阅读完整文章。原帖与评论继续使用 B 站原版页面。

顶部搜索沿用原版模式的搜索建议、历史和键盘操作。右侧消息打开 [B 站私信页面](https://message.bilibili.com/?spm_id_from=333.1007.0.0#/whisper)，按原通知设置合计 `reply / at / like / sys / follow / unfollow` 未读数，超过 99 显示 `99+`。仅在极简页面可见时每 60 秒刷新，返回窗口时也会刷新，两次请求至少间隔 10 秒；读取失败显示 `?`，不会假报为 0，也不会标记消息已读。

首次依次加载 4 页，下滑接近底部自动续载。视频与帖子共用已加载数据并保存各自滚动位置；同页切换模式保留内容；主动刷新重新读取动态列表，并复用当前页内仍有效的完整正文缓存，整页刷新或更换账号重新读取。帖子图片使用已知尺寸占位，正文补全保留卡片所在列；切换筛选时从左重新紧凑分列。可见性观察器复用，新增内容增量处理，并合并连续布局更新，减少重复扫描与分列。普通帖子已有非空文字但仍是摘要时，继续补取原始 Opus 正文；文章只保留卡片摘要。未补齐时保留非完整状态和原文入口。尺寸缺失或正文扩展仍可能引起局部高度变化。

视频标签下会预取首批少量帖子正文，进入帖子标签后优先读取当前阅读区域附近的内容。接口先返回的正文先显示，后续再补齐内容，补取失败保留已显示的部分。正文请求共用两路并发队列，并设置请求间隔；连续失败或遇到风控时暂停，可手动继续。成功读取的完整正文按账号隔离缓存在当前页内，最多保留 200 条、有效期 5 分钟。空响应或不完整响应保留已经读到的正文；权限失效时不使用旧内容补回。

视频封面底部显示观看位置：无记录为白字，实际播放时间为蓝字；95% 或剩余不足 30 秒只决定完成遮罩，实际时间不被改写。接口明确返回结束标记或播放器实际结束时，用绿字显示总时长 / 总时长。未完成视频可通过封面右上角的 36px 纯时钟按钮添加稍后再看，图标不含加号；完成视频隐藏该按钮，批量模式仍可手动选择尚未在列表中的条目。添加成功后常显蓝底勾选状态；单条添加不展示批量统计，旧列表快照不会覆盖本次添加成功状态。标签右侧可进入批量选择，已有条目仅显示文字；每天标题旁可添加当前已加载的当天未看完视频。顶部入口显示数量并打开 B 站原版 `/watchlater/list#/list` 页面。

视频封面与动态顶部以粉色显示 B 站明确返回的结构化充电或专属标记。本版隐藏封面下载入口，保留底层实现，原有下载组件继续可用。

帖子顶部的“疑似广告”分组默认折叠，可展开查看原帖。规则结合营销语境、行动引导和优惠红包等信号；在已加载内容中比较 7 天内较长正文与配图，仅双方正文都完整时进行近似归并，避免相同配图导致误并；归并后保留一份并显示数量。普通抽奖话题或简短问候不会单独触发；本地启发式规则可能误判或漏判，归并不删除账号中的动态。

正文中明确包含 B 站原生抽奖节点与有效抽奖 ID 时显示“参与抽奖”。点击后在当前列表内打开独立弹窗，加载同源 B 站官方抽奖页面，首页不跳转；等待官方页面实际内容出现后结束加载，登录与参与由原生页面处理，脚本不自行提交操作。异常时可打开原帖。抽奖动态使用淡透明粉色背景与粉色悬停边框；普通“互动抽奖”话题不会自动作为原生抽奖入口。

UP 极简模式向下滚动超过一屏后，右下角显示返回顶部按钮。原版、竖屏模式和全屏播放时隐藏；开启系统“减少动态效果”时直接返回，否则平滑滚动。

观看标记、历史同步范围及添加顺序的完整说明见 [README](https://github.com/NeverOvO/Bilibili-Clear/blob/beta/README.md#观看标记与同步范围)。页面保留本次同步条数、实际覆盖时间及错误提示，分 P 上下文读取失败时有限重试。

网页标签保留完整原标题，仅在末尾追加一个 `Clear`，并随原生标题更新；下载命名使用未标记的原始标题。

脚本开始执行后读取已保存的首页模式，命中关注极简模式时，在运行库初始化前挂载白底小电视过渡层。Lodash 运行库随脚本打包。核心设置与页面容器就绪后提前挂载极简页面，无需等待原站全部资源加载；极简页面挂载完成后移除过渡层。超过 12 秒、启动失败，或点击“返回原版首页”时，本次打开恢复原版，保留已保存的模式选择；关闭功能或卸载组件也会清理遮罩。脚本开始执行前的画面无法控制，仍可能出现原版首页闪现。

Beta 5 仅在 `www.bilibili.com` 首页自动显示右下角启动诊断面板，可复制、收起或关闭。日志记录脚本执行和页面状态、模式读取、遮罩挂载与移除原因，以及运行库、设置、内置功能和极简页面的加载时间；浏览器支持时记录 first-paint 与 FCP。遮罩挂载后的绘制机会另行记录，不能单独证明用户已看到过渡界面，首次绘制也不能判断是否为原版内容。脚本入口时间无法单独拆分注入与解析耗时。本版用于定位首屏闪现，不延长过渡时间。

诊断日志仅在当前页面内存中保留有限条目，不上传或持久化，不记录 Cookie、账号信息和完整设置。剪贴板访问失败时可在文本框中手动复制；关闭面板后刷新首页可重新记录。

**竖屏模式** 使用 B 站网页推荐源和同域主站播放器，沿用已有登录会话。剩余 4 条时提前补充推荐，用固定位置的两个槽位保留当前与下一条播放器，并预载封面；下一条不主动播放，切换时激活。旧文档回调隔离，避免把加载过渡误判为离开当前视频；真实串视频或切换分 P 的保护保留。支持上一条 / 下一条、滚轮、上下键和滑动，保留原生控制。浏览器阻止有声播放时，可点击播放入口启动。首次封面最多覆盖 3 秒，随后露出原生界面；当前视频真实播放后清除可恢复错误，终止类错误保留。等待下一条时返回或改变操作会取消旧跳转意图，返回操作保留共享补推荐任务。网络、过滤结果和原生播放器仍可能造成等待。

这是 Beta 功能，数据错误会显示在页面上，可重试或切回原版首页。广告卡片与可识别短剧会被过滤，未标记的植入广告或短剧可能漏过。观看记录和手动屏蔽列表按账号保存在当前脚本管理器，不上传至项目服务器。本轮仅作源码调整与发布构建，未执行测试、类型检查、lint、代码审计或浏览器实测，也未测量性能或复现 Safari 页面自动重载。测试版从 `beta` 更新，正式版 4.0.0 的 `master` 分支不变；此前的 [4.0.0 审计记录](https://github.com/NeverOvO/Bilibili-Clear/blob/beta/doc/release-4.0.0-audit.md) 不包含本轮新增改动。
