# Bilibili Clear 4.0.0 审计记录

日期：2026-10-27。审计基于 Beta 11（`2c8b27bb9`），覆盖 beta 相对原正式版 master 的全部功能改动，并检查初始化、设置迁移、扩展安装与更新、网络请求、跨域存储、运行库和本地开发服务。全仓 TypeScript / Vue 文件执行静态检查；新增回归测试执行实际源码或实际编译产物。

发现的问题已修复，未留下发布阻断项。本次记录不代表所有上游历史代码都经过逐行形式化验证，也不保证 B 站后续接口变化不会影响功能。

## 已修复的问题

| 范围 | 问题与处理 |
| --- | --- |
| 设置迁移 | 普通升级中途写入失败可能先删除旧组件设置。现在先写入完整迁移恢复记录，全部持久化成功后清除；失败后停止后续持久化，下次启动恢复。 |
| 观看进度 | 替换视频元素后可能继承旧元素的就绪与采样依据，误记完成。替换时清除旧依据。95% / 不足 30 秒的遮罩规则与真实观看时间继续分别处理。 |
| 关注列表 | 过滤异常、超出范围的发布时间，避免日期格式化使列表报错。保留账号隔离、分页缓存、详情补齐和批量稍后再看顺序。 |
| 竖屏播放器 | 同视频 iframe 重载可能沿用旧播放状态，产生持续黑屏。按新文档重置状态和启动超时，保留视频归属校验、预加载静音及资源释放。 |
| 搜索 | 远端建议改为纯文本处理，编码查询参数；隔离过期响应，处理 provider 失败、卸载后返回和异常历史数据。 |
| 弹窗 | 正确识别多层 Vue 包装中的 VPopup，修复 Esc 被拦截却未关闭内部弹窗的情况。 |
| 扩展更新 | 下载结束后再次核对功能类型、安装状态、实时更新记录及 URL；最近更新操作使用原记录，避免卸载后被重新装回。 |
| 跨域存储 | 同时校验官方域名与实际 iframe 窗口，拒绝无效消息；请求超时或失败后清理等待者，过期写入不会在 iframe 迟到时继续发送。 |
| 输入与分页 | JSON 文件导入使用 JSON.parse；拒绝空第一页与非零总量不一致的响应，避免触发大量无效分页。显式代码扩展接口继续保留。 |
| 开发命令 | 服务器在结果返回前关闭、响应格式错误、命令失败或超时均明确返回失败，不能误报退出码 0。 |
| 构建 | 修正 Vue 2 普通样式请求不存在的默认导出，保留样式注入、scoped 样式和 CSS module 绑定；不使用告警屏蔽。 |

## 依赖与兼容性边界

Lodash 升级至 4.18.1、protobufjs 升级至 7.6.6、Marked 升级至 4.3.0，并更新兼容的开发依赖和锁文件。Vue 2 样式编译使用修复后的 PostCSS 8；开发用静态服务器绑定本机地址。

根项目依赖审计剩余 **1 项 low**，moderate / high / critical 均为 0；registry 子项目各等级均为 0。[依赖结果摘要](release-4.0.0-dependencies.json)保留公告链接。

剩余项是 [Vue 2 parseHTML 编译器正则风险](https://github.com/advisories/GHSA-5j4c-8p2g-v4jx)。正式包使用 `vue.runtime.common.prod.js`，source map 确认未打入模板编译器；本次不进行会影响原组件体系的 Vue 3 迁移。Vue 2 已结束官方维护，这项依赖风险仍保留在记录中，不能将本次结果表述为“依赖零告警”。

运行库升级依据：[Lodash](https://github.com/advisories/GHSA-r5fr-rjxr-66jc)、[protobufjs](https://github.com/advisories/GHSA-f38q-mgvj-vph7)、[Marked](https://github.com/markedjs/marked/security/advisories/GHSA-rrrm-qjm4-v8hf)。
