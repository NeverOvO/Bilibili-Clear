# 4.1.1 发布审计记录

## 已修复问题

| 问题 | 处理结果 |
| --- | --- |
| 正文已经请求成功，但在合并渲染前切换模式会丢失正文，且已完成状态阻止重试 | 隐藏视图前提交同账号的待渲染正文；账号切换和销毁继续丢弃旧结果 |
| 多卡片使用相同图片地址时重复占用预加载槽位、覆盖清理回调 | 请求进入队列即去重，完成、失败、超时和停用均释放槽位 |
| 快速切换图片时旧图事件覆盖当前图的状态 | 图片加载和错误事件匹配当前图片后才更新状态 |
| 图片预览打开时 Vue 属性类型警告 | opener 使用 HTMLElement 类型 |
| WebKit 默认 Tab 顺序跳过按钮，焦点跑出图片弹窗 | 在预览内显式循环 Tab / Shift+Tab，关闭时恢复原焦点及背景状态 |
| 首页提前挂载失败后不能重试，迟到的样式仍可能残留 | 每次挂载独立取消；失败清理样式，普通组件入口允许重试，保留路由与卸载隔离 |
| 首页 Beta 标识未区分正式渠道 | 按编译分支显示，正式版隐藏 |
| Beta 启动诊断面板遮挡返回顶部按钮 | 面板上移并限制视口高度，透明 host 不拦截点击，面板自身保持可操作 |

同时清理新增代码的 lint 错误，修正旧启动测试中已过时的 DOM 模拟和超时假设。

## 依赖告警

锁文件审计仍有既有告警：根项目 1 个低危、4 个中危，registry 1 个中危；没有高危或严重告警。重复依赖路径会分别计数，涉及 3 个公告，不能将此次审计描述为“依赖零漏洞”。

- [Vue parseHTML ReDoS](https://github.com/advisories/GHSA-5j4c-8p2g-v4jx)：生产构建使用 Vue runtime-only，模板在构建时编译，不将远端正文作为 Vue 模板编译。
- [minimatch globparts amplification](https://github.com/isaacs/minimatch/security/advisories/GHSA-g3hv-75wg-m249)：当前用途在构建、lint、类型和本地服务工具链。项目直接 glob 调用使用固定目录模式；其依赖内部可能启用受影响优化，不能仅凭项目没有显式设置该选项就排除风险。
- [glob AbortSignal cancellation bypass](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4)：项目直接调用使用同步固定目录扫描，不将 AbortSignal 当作不可信扫描的安全边界。生产脚本的 source map 中没有 glob / minimatch 模块。

当前新增运行路径不满足上述公告的已知触发条件，未把跨主版本工具链升级混入本次功能发布。受影响包仍在开发依赖中，后续升级需覆盖构建、lint 和本地服务兼容性。
