点击左下角设置按钮上方的模式按钮，在 **原版精简** 和 **关注极简** 之间切换，原有功能及设置保持可用。

极简首页显示“UP极简模式”，顶部 GitHub 图标与 NeverOvO 名称打开项目仓库。默认显示“视频”标签；切换“帖子”后以多列瀑布流展示标题、正文和自然比例图片，原帖与评论通过链接进入 B 站原版页面。内容按发布时间和日期分组，只显示已确认关注的作者。

首次依次加载 4 页，下滑接近底部自动续载。视频与帖子共用已加载数据并保存各自滚动位置；同页切换模式保留内容，主动刷新、整页刷新或更换账号重新读取。帖子在接近阅读区域前加载正文和图片，使用已知尺寸占位，并保持卡片所在列；尺寸缺失或正文扩展仍可能引起局部高度变化。

视频封面底部显示观看位置，右上角可直接添加稍后再看。添加成功后图标常显为蓝色书签勾选；单条添加不展示批量统计。标签右侧可进入批量选择，已有条目仅显示文字；每天标题旁可添加当前已加载的当天未看完视频。顶部入口显示数量并打开 B 站原版 `/watchlater/list#/list` 页面。

观看标记、历史同步范围及添加顺序的完整说明见 [README](https://github.com/NeverOvO/Bilibili-Clear/blob/beta/README.md#观看标记与同步范围)。页面保留本次同步条数、实际覆盖时间及错误提示。

保持极简模式进入首页时，脚本提前隐藏原版内容以减少闪现；启动失败会恢复原版。实际效果取决于脚本管理器的注入时机。

**短视频** 使用 B 站网页推荐源和同域主站播放器，沿用已有登录会话。剩余 4 条时提前补充推荐，保留当前与下一条播放器并预载封面；下一条不主动播放，切换时激活。支持上一条 / 下一条、滚轮、上下键和滑动，保留原生控制。浏览器阻止有声播放时，可点击播放入口启动。网络、过滤结果和原生播放器仍可能造成等待。

这是 Beta 功能，数据错误会显示在页面上，可重试或切回原版首页。广告卡片与可识别短剧会被过滤，未标记的植入广告或短剧可能漏过。观看记录和手动屏蔽列表按账号保存在当前脚本管理器，不上传至项目服务器。本次未执行自动化或浏览器验证。
