首页可在 **原版精简** 和 **关注极简** 之间切换，原有功能及设置保持可用。

关注极简使用当前登录账号的关注动态，将 UP 主发布的视频与帖子分开，按发布时间和日期分组。只显示已确认关注的作者，不混入推荐、直播或转发内容。接口返回范围以 B 站为准，点击“加载更早的关注内容”继续翻页。

视频封面显示观看位置；有明确完成记录时显示灰色“看完了”印章。多 P 视频分别记录进度，只有各分 P 均有完成证据才标记整条完成。历史同步补充最近最多 90 条记录，本地记录保留最近 1000 条；无记录不代表从未观看。

**短视频** 使用 B 站网页推荐源和官方嵌入播放器。点击上一条 / 下一条，或在播放器外使用滚轮、上下键及上下滑动切换。播放器内部保留 B 站自己的交互；声音、清晰度及播放权限由原生播放器控制。广告卡片和可识别的短剧内容会被过滤，未标记的植入广告或短剧无法保证识别。

这是 Beta 功能，B 站接口、推荐结果和登录状态可能影响可用性。数据错误会显示在页面上，可重试或切回原版首页。观看记录和手动屏蔽列表按账号存放于当前脚本管理器，不上传至项目服务器。
