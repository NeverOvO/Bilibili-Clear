# Bilibili Clear 版本回退

在 [Bilibili Clear Releases](https://github.com/NeverOvO/Bilibili-Clear/releases) 中选择历史版本，阅读该版本说明，并安装附件 `bilibili-clear.user.js`。

本体与内置功能作为同一版本发布，应一起回退。若要暂时停留在某个版本，在脚本管理器中关闭该脚本的自动更新，并关闭设置中的“新版本提示”；恢复自动更新后可继续获取新版本。

新版本添加的设置可能无法被旧版本识别。不要使用 Bilibili Evolved 或 HomeFix 的安装文件替代 Bilibili Clear 的历史版本。

3.0.0 是 Bilibili Clear 首个正式版本，更早的 HomeFix 不属于本项目的可回退发行版。
